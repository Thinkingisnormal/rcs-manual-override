# RCS: Manual Overide
A very simple game that is intended to be hard. Maunally control all eight thrusters of a space pod to evade the incoming astroid feild, invetably die, get your action report. 

# Why did I make this
I didn't want to put the bare minimum into my AP CS:P exam, so I created this. It fills every box for the exam, including an algorithm that iterates, something, somehting.
